### The problem I keep circling back to

Healthcare ML that's accurate on average and wrong on the margins isn't actually working — it's just failing quietly. I spend most of my time trying to close that gap without pretending accuracy doesn't matter either. That instinct is what's behind most of what's below.

I'm finishing a B.Sc. in Computer Engineering at **Haliç University, Istanbul** (July 2026, valedictorian), and I'm looking for **ML Engineer / AI Engineer / Systems Engineer** roles where that tradeoff is taken seriously.

### What I've built

**[Algorithmic Fairness & Bias Mitigation](https://github.com/BARAAABID/algorithmic-fairness-neurodegenerative-disease)**
A clinical model was accurate but biased against a subgroup of patients. I cut the fairness gap by 75% for a 2-point accuracy cost — then re-ran the whole approach on a second disease and 10 different classifiers to check it wasn't a fluke.
`Python` `CatBoost` `SHAP` `AIF360`

**[MindGage Infrastructure](https://github.com/BARAAABID/MindGage-Infrastructure)**
Physiological check-in data is noisy and hard to interpret in real time. This is a containerized FastAPI backend that turns it into cognitive-load insights using the Gemini API — validated, tested, and built to run the same way in production as it does on my laptop.
`FastAPI` `Docker` `SQLAlchemy` `Gemini API`

**[EEG Ingestion API](https://github.com/BARAAABID/eeg-ingestion-api)**
512Hz biosensor streams don't wait for slow code. An async ingestion pipeline that held 100% success under concurrent load, using WAL-mode SQLite and semaphore-bounded concurrency instead of just hoping the database keeps up.
`FastAPI` `aiosqlite` `AsyncIO`
